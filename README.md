# AlliEats - Restaurant Menu Management & Food Ordering System

AlliEats is a web-based food ordering platform built with ASP.NET Core and Razor Pages. The system provides comprehensive functionality for both administrators and customers to manage menus, place orders, and track deliveries.

## 🚀 Features

### For Administrators
- **Menu Management**
  - Add, edit, and delete menu items
  - Upload and manage food images
  - Organize items by categories (Appetizers, Main Courses, Desserts, Beverages)
  - Set prices and manage item availability
  - Search and filter menu items

- **Order Management**
  - View all customer orders in real-time
  - Update order status through workflow (Pending → Confirmed → Preparing → Ready → On the Way)
  - Track order history and details
  - Manage order fulfillment

### For Customers
- **Menu Browsing**
  - Browse categorized menu items with images
  - View detailed item descriptions and prices
  - Filter items by category

- **Shopping Cart**
  - Add items to cart with quantity selection
  - Review and modify cart items
  - Proceed to checkout

- **Order Tracking**
  - Real-time order status updates
  - Track delivery progress through multiple stages
  - Confirm order receipt
  - Cancel orders (while in pending status)
  - View complete order history

- **Profile Management**
  - Update personal information
  - Manage delivery addresses and preferences
  - Set delivery instructions
  - View profile completion status

- **Reviews & Ratings**
  - Leave reviews for received orders
  - Rate food quality and service
